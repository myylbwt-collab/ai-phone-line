# קו טלפון אישי עם בינה מלאכותית (גרסה 2.0 משודרגת) 🚀🔥

מערכת מלאה ומוכנה להפעלה לחיבור קו טלפון של **ימות המשיח** לבינה המלאכותית המתקדמת **Google Gemini** בעיבוד שמע ישיר (Audio-to-Audio) עם זמן תגובה מהיר במיוחד (4-5 שניות בלבד!) ודיוק גבוה בעברית.

---

## 🌟 מה חדש בגרסה 2.0 (משודרגת ויציבה)

1. ⚡ **מהירות שיא עם `gemini-3-flash-preview` (מענה תוך 4-5 שניות):**
   מודל על שעובר אופטימיזציה ישירה לקובצי קול, מפענח שמע בעברית ומייצר תשובה תוך שניות בודדות!
2. 🛡️ **מנגנון זיכרון חכם למכסות (Circuit Breaker & Cooldown):**
   אם מודל מגיע למגבלת מכסה יומית (שגיאת 429), המערכת רושמת לעצמה ונכנסת לצינון של שעה. בכל השיחות הבאות היא מדלגת עליו ב-**0 מילישניות** ועוברת ישירות למודלים הזמינים. כעבור שעה היא בודקת שוב אוטומטית אם המכסה התחדשה.
3. 🧠 **זיכרון שיחה רציף (Multi-Turn Conversation):**
   המערכת זוכרת את כל השאלות והתשובות במהלך אותה השיחה! ניתן לשאול שאלות המשך טבעיות.
4. ⏳ **הסרת מגבלת אורך ההקלטה:** אין ניתוקים אחרי 30 או 90 שניות. אפשר לדבר בחופשיות ולסיים בהקשת #.
5. 🎵 **מוזיקת המתנה מובנית בזמן החשיבה (Music on Hold):** החבילה כוללת M0000.wav.
6. 🔕 **ביטול הצורך להקיש פעמיים 1:** החבילה כוללת M1000.wav.
7. 🤖 **הגדרה אוטונומית:** הפרויקט כולל סקריפט אוטומטי מלא.
8. 🔒 **לוח בקרה אישי מוגן בסיסמה:** ברירת מחדל 1234.

---

## 🛠️ מה צריך כדי להתחיל?
1. מפתח API של Google Gemini.
2. מערכת בימות המשיח ומפתח API.
3. חשבון GitHub ו-Render.

---

## 📞 הגדרה ידנית
1. העלו את הקבצים ל-GitHub.
2. ב-Render צרו Web Service חדש מתוך המאגר.
3. הגדירו את משתני הסביבה המופיעים ב-`.env.example` או `render.yaml`.
4. לאחר הפריסה, הגדירו `PUBLIC_BASE_URL`.
5. הריצו את סקריפט ההגדרה האוטומטי של ימות המשיח.

חייגו למערכת, הקישו על השלוחה, ותיהנו מקו אישי וחכם עם בינה מלאכותית!
